# Nodal

Nodal is a bit-packed mesh protocol that works without a central server or trusting individual nodes.

> [!WARNING]
> Nodal is still in very early development, so expect limited features and a few rough edges.

For the technical details, see [SPEC.md].

## Features
- Message sending through the mesh
- Ed25519 signatures over entire packets
- Time-to-live (TTL) to stop packets from looping forever
- Low protocol overhead
- Node identities
